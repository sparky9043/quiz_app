# Online Quiz Application

## Purpose
The purpose of this application is to streamline online quiz taking procedures into a few simple steps.
Teachers can create questions and quizzes, while students can take the quizzes and have it graded

## Roles
### Teacher
1) Create/Edit/Delete questions and options for each questions
2) Package questions into quizzes
3) Publish quizzes for students to take

### Student
1) View questions but cannot create/edit/delete questions
2) Take quizzes using an online quiz generator
3) Have their quizzes automatically graded
4) View their grades

## Tech Stack
### Backend
1) Server: Node/Express + TypeScript
2) Database: Supabase (PostgreSQL)
3) Authentication: bcrypt
4) Authorization: JSON Web Token

### Frontend
1) Library/Framework: React + TypeScript
2) Style: TailwindCSS
